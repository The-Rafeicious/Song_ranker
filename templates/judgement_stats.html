How these figures work {% if mode=='spotlight' %}

One completed split gives each track one observation. Support uses 3 × points / (12 + 2 × points), then moves lightly tested tracks toward 50% using current collection evidence. Equal three-point shares are neutral. Shared Spotlight contributes adaptively to Overall's preference family; public Elo stays based on matches. Up to 50 supported tracks are shown.

{% elif mode=='vibe' %}

Each grid describes the heard preview independently. Unplaced grids and unreviewed tags stay unknown. Means use the 0–4 axes; spread is the combined standard deviation of X and Y, so a larger value means more varied descriptions. Heatmaps include saved placements for removed tracks; track tables use the current catalogue. Tags use reviewed rounds as their denominator and never change catalogue memberships. Descriptions have no quality weight in Overall.

{% endif %}

Coverage uses current tracks with preview URLs. Selectors and evidence weights adjust as the catalogue and results change. Skips and abandoned offers are retained for seven days; completed rounds are kept. Listening counts playback before a saved decision.
