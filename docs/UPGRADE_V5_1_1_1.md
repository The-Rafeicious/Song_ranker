# Home, navigation and mode presentation

These display conventions remain in V5.1.1.2. Use the
[current installation and deletion guide](UPGRADE_V5_1_1_2.md). The original
V5.1.1.1 release notes remain unchanged in [release history](../update_logs/V5_1_UPDATE.md).

Home uses automatic four/two/one-column placement, with seven current cards.
Shared Spotlight 🔦 and Vibe Map 🗺️ use real emojis. Both reuse Standard Vote’s
centred full-cover play/pause overlay and linked proper-album metadata.
Navigation uses larger labels and a relative wordmark, with responsive header
rows. The spectrum includes all current mode accents and ends with Vibe’s red.
Stats has one link per line and uses normal page scrolling, without an inner
scrollbar. See [PAGE_STYLE.md](PAGE_STYLE.md) for composition ownership.
